# Тема Avito AI для WordPress

## Установка
1. Установите Local (localwp.com) и создайте сайт.
2. Скопируйте папку `avito-ai` в `wp-content/themes/` сайта.
3. В папке темы выполните `composer install` (ставит Carbon Fields в `vendor/`).
4. В админке: Внешний вид → Темы → активируйте «Avito AI». При активации создаётся страница «Главная» с готовыми разделами.
5. Тексты разделов: Страницы → Главная → блок «Разделы страницы». Меню, логотип и плавающая кнопка: «Настройки сайта».

## Разметка в текстовых полях
- `**жирный**`
- `{{акцент}}` — акцентный цвет
- `((слово))` — акцент только на мобильной версии (заголовок видео)
- `||` — перенос строки на десктопе (на мобильной скрывается)

## Что перенесено
Все разделы: шапка, Hero, видео и статистика, Проблемы, Решение, Подключение, Интеграции, Детали, Калькулятор, Частые вопросы, Форма заявки, Тарифы, футер и плавающая кнопка «Демо».

Если на странице «Главная» не хватает разделов, в админке на её странице появится кнопка «Добавить недостающие разделы».

## Заявки с форм
Формы отправляют данные не на сервер заявок напрямую, а на сам сайт (`/wp-json/avito/v1/lead`, файл `inc/leads.php`). Токен сервера заявок добавляется там, на стороне WordPress, поэтому в коде страницы и в запросах браузера его нет.

Адрес сервера и токен задаются в `wp-config.php` (выше строки «That's all, stop editing!»):

```php
define('AVITO_LEADS_URL', 'https://api.example.ru/postUserData');
define('AVITO_LEADS_TOKEN', 'значение ACCESS_TOKEN из .env сервера заявок');
```

Пока значения не заданы, форма покажет ошибку отправки, а в журнал PHP попадёт сообщение `Avito leads: … are not set`.

### Капча (Яндекс SmartCaptcha)
Невидимая проверка при отправке формы, внешний вид форм не меняется. Включается двумя ключами из консоли Yandex Cloud (SmartCaptcha → создать капчу, тип «Невидимая», в списке разрешённых сайтов указать домен лендинга) в том же `wp-config.php`:

```php
define('AVITO_SMARTCAPTCHA_CLIENT_KEY', 'ключ клиента');  // публичный, попадает на страницу
define('AVITO_SMARTCAPTCHA_SERVER_KEY', 'ключ сервера');  // секретный, остаётся на сервере
```

Пока ключи не заданы, формы работают без капчи. Если задан ключ сервера, заявки без подтверждённого токена обработчик отклоняет (403). В React-версии ключ клиента задаётся переменной `REACT_APP_SMARTCAPTCHA_SITEKEY`.

### Ограничения
Защита от злоупотреблений: не больше 5 заявок за 10 минут с одного IP, повторная заявка с того же email в течение суток на сервер не пересылается. Страница редиректа после отправки задаётся в разделе «Форма заявки» (поле «Куда перенаправить после успешной отправки»).
